# Roblox Server Locations

A community maintained collection of observed Roblox server IP ranges and server locations.

This repository is an independent research project. It is not affiliated with or endorsed by Roblox. Locations are estimates based on observations, public routing data, and IP geolocation; they may be incomplete or inaccurate.

## IP range list

The complete country and city organized list is in [robloxserveriplist.txt](robloxserveriplist.txt). It includes Roblox related ranges and separately marked AWS ranges.

- CIDRs are kept as listed in the source dataset.
- Entries marked `(AWS)` are AWS address ranges associated with the listed location in the dataset; AWS ownership or geolocation alone does not prove that a range hosts Roblox servers.
- Some entries are approximate, uncertain, or marked as possibly decommissioned. See the notes in the text file.

## Scope and limitations

Server infrastructure, routing, and IP allocations change. A listed address may stop being active, and IP geolocation databases can point to a nearby city rather than the actual facility. The list is for community research and should not be treated as an official Roblox datacenter directory or a guarantee that an IP responds to ICMP.

## Contributing

Corrections and new observations are welcome. Please include the IP or CIDR, the proposed location, when it was observed, and supporting evidence where possible. Mark uncertain findings clearly so they can be reviewed.
